# 04 · 首次使用引导与右栏信息架构

> 状态：v1 已实施（2026-10-30，见文末「实施记录」）
> 目标：第一次打开软件的用户，**60 秒内完成一次成功渲染**，3 分钟内知道「下一步该点哪」。

## 0. 一句话结论

现在缺的不是「一篇更好的教程」，而是**一条不会失败的主路径**。

右栏六组折叠解决的是「排版对齐」，没有解决「我现在该做什么」；而内置预设引用的字体在发布包里并不存在，新用户按「预设 → 导入 → 调字体」走，第一步就必然报错。所以顺序应该是：

1. **先修冷启动**（没有字体也能出第一张图）
2. **再改信息架构**（按任务切换面板，而不是继续加折叠组）
3. **最后做引导**（任务选择 + 空状态 + 清单 + 情境提示 + 帮助重构）

---

## 1. 你的评估：依赖顺序对，认知顺序不对

你描述的流程是：

1. 在预设里选一个预设
2. 在导入素材里导入「正文文本」或「文档底图」
3. 在此基础上改手写字体、笔迹、多人角色

**作为「依赖顺序」，基本正确**：渲染确实需要字体 + 纸张 + 内容，角色是后置的。

**作为「新手认知顺序」，不成立**，原因有四条：

1. **新手不知道「预设」是什么，也不知道该选哪个。**
   现有预设名是字体品牌（华阳体、云烟体、李国夫），对没接触过字库的人没有信息量；预设里还混着纸张、边距、扰动，用户无法预判选了会发生什么。
2. **字体不是「导入后可以改」的可选项，而是硬前置。**
   发布包不包含字体，预设里的 `fonts/华阳手写体.ttf` 只是占位名。选完预设 → 自动渲染 → 状态栏报「字体文件不存在」，用户会直接判定「这软件用不了」。
3. **「正文文本」和「文档底图」不是同一层的二选一。**
   前者进入段落编辑器（文本排版），后者进入区域框选 / 高亮识别 / 多角色（文档填空）。这是两条工作流，不是一个选项的两种素材。
4. **少了「导出」和「微调」两步。**
   用户真正会问「然后呢」的地方，恰恰是：区域框怎么调、导出去哪了、怎么保存这套参数。

更准确的心智模型是：

> **先选「我要做什么」→ 再给内容 → 再调字迹 → 最后拿走成品。**
> 依赖关系由界面替用户兜住，而不是让用户背顺序。

## 3. 目标模型：两条工作流、四个阶段

```text
入口（首次启动 / 空状态）
├─ A 写文字（信 / 作业 / 笔记）
│   1 选字迹与纸张（推荐方案） → 2 输入或导入文字 → 3 预览微调 → 4 导出
│
└─ B 填文档（试卷 / 表格 / 实验报告）
    1 导入 PDF/Word 底图（说明高亮规则） → 2 自动识别区域与角色
    → 3 检查区域、给每种笔迹选字体 → 4 导出
```

关键不是把六个组重新排序，而是：**入口先分叉，分叉后右栏只显示这条工作流需要的东西。**

- 空状态：开始卡（3 个动作 + 示例）
- 文本模式：内容 / 字迹 / 版式 / 导出
- 文档模式：文档 / 区域(N) / 角色(N) / 字迹 / 导出
- 段落对齐、扰动、错字、边距：全部收进「高级」

## 4. 首启引导：五层，从轻到重

### 4.1 首次启动：只问一个问题

一个弹窗、一屏，三张卡片：

- **写文字**（信 / 作业 / 笔记）
- **填文档**（试卷 / 表格 / 实验报告）
- **先看示例**（30 秒）

选择后：

- 写文字 → 载入推荐预设，光标落在正文框
- 填文档 → 直接打开文件选择器，旁边用一句话说明「Word 里先高亮要手写的部分，另存 PDF 再导入」
- 看示例 → 载入示例文字 + 推荐预设，立即渲染

**第二屏只在「没有可用字体」时出现**：

- 系统字体列表（楷体 / 行楷优先）
- 打开 `fonts/` 文件夹
- 下载免费可商用字体（霞鹜文楷等）
- 「先跳过，用系统楷体」

原则：**向导的终点必须是「看到一张成品」，而不是「读完一段说明」。**
完成后写 `localStorage` 标记；帮助里提供「重新观看引导」。

### 4.2 空状态：把预览区变成入口

把 `PreviewPane.vue:451` 的一行提示换成开始卡：

```text
┌──────────────────────────────────────────┐
│  把文字变成手写，三步就好                  │
│                                          │
│  [ 写一段文字 ]   [ 导入 Word 正文 ]      │
│  [ 导入 PDF / Word 底图 ]  试卷 / 表格    │
│                                          │
│  [ 看 30 秒示例 → ]                       │
└──────────────────────────────────────────┘
```

- 背景放一张半透明示例图（标注「示例」），先让用户看到产品价值
- 无字体时，卡片顶部加一条黄色横幅：「还差一款手写字体」+「选择字体」

### 4.3 常驻三步清单（不是弹窗）

位置：右栏顶部或预览区左上角，紧凑、可折叠。

- [ ] 选好字迹（`fontPath` 非空）
- [ ] 放入内容（正文非空，或已导入文档）
- [ ] 导出第一张（导出成功）

由真实状态自动勾选；三条都完成后折叠成「✓ 已上手」；可在帮助里重新打开。

比 tour 好的地方：不打断、可恢复、状态真实、不重复打扰。

### 4.4 情境提示：最多 3 条

| 触发 | 指向 | 文案 |
|------|------|------|
| 首次渲染成功 | 笔迹角色 | 想让两个人写？给角色换字体就行 |
| 首次导入文档 | 文字区域 | 识别到 N 处，点一下可拖动微调 |
| 首次导出成功 | 预设 | 这套参数可以存成预设，下次一键复用 |

每条只出现一次，「知道了 / 不再提示」写入 `localStorage`。
**不做**全屏遮罩式 10 步 tour。

### 4.5 帮助中心：从说明书改成「按任务查」

- Tab 1 **三分钟上手**：两条工作流各一张卡 + 15 秒 GIF
- Tab 2 **试卷 / 表格填空**：保留现有内容
- Tab 3 **选框与角色**：选框、笔迹角色、手动画区域
- Tab 4 **真实感调优**：扰动、错字、FAQ
- Tab 5 **更多功能**：预设、纯背景预览、边距、深色模式、更新
- 每个折叠组标题右侧加「?」，深链到对应 Tab（v1 先完成分栏与文案同步，深链在 P3）
- 文案与界面标签统一（字体 / 背景图片 / 导出 PDF）
- 首次向导最后一屏告诉用户「随时可在右下角打开」

## 5. 右栏重排：从六个同级折叠到「摘要 + 三步」

### 5.1 现在的结构

```text
① 文本内容（默认展开，含大编辑器）
② 文字区域（空则折叠）
③ 笔迹角色（默认折叠）
④ 导入素材（默认展开：两个导入 + 背景 + 字体）
⑤ 笔迹仿真与版式（默认折叠）
⑥ 预设（默认折叠）
```

问题：这是**功能域**分类，不是**任务阶段**分类。六个组权重相同，用户看不出先后。

### 5.2 建议结构

```text
┌ 当前方案 ───────────────────────────────┐
│ 模板 [A4 白纸 · 工整 ▾]      ● 已修改     │
│ 字迹 [楷体（系统） ▾]        ✓           │
│ 纸张 [A4 纯白 ▾]             ✓           │
└─────────────────────────────────────────┘
① 内容   [ 写文字 ] [ 导入 Word ] [ 导入底图 ]
         摘要：3 段 · 128 字          [编辑]
② 字迹   主字体 [▾]   墨色 [●]   多人书写 ▸
③ 版式   字号 / 行距 / 边距 [调整]   高级 ▸
─────────────────────────────────────────
[ 导出图片 ]   [ 导出 PDF ]
```

### 5.3 四条规则

1. **一屏一条主路径**：默认只展开当前阶段，完成即折叠成一行摘要。
2. **重编辑器进弹窗**：正文编辑、区域编辑、角色管理都改成「摘要行 + 编辑」，不要常驻大控件。
3. **高级参数下沉**：扰动、错字、边距、边界提示收进「高级」抽屉，默认不可见。
4. **一个主按钮**：每阶段只有一个 primary；预览是自动的，**导出才是终点**。

### 5.4 条件显示

- **文字区域**：仅文档模式 / 已有区域时出现，标题带数量
- **笔迹角色**：仅角色数 > 2 或文档模式时出现；否则以「多人书写」入口出现
- **段落工具**（对齐 / 缩进）：仅文本模式
- **预设**：升级为顶部「当前方案」，不再是第六组

### 5.5 视觉层级

- 步骤编号 ①②③，字号大于组内标签
- 摘要行用 12px 次要色，右侧「修改」
- 步骤卡比高级卡多一层浅底 / 边框，形成主次
- 底部只保留导出；翻页留在预览下方
- 状态栏错误改成可操作横幅（见 6.3）

## 6. 预设系统：从「参数文件」到「可选择的方案」

### 6.1 状态可见

- 增加 `store.currentPresetPath`：下拉保留当前值
- 参数改动后显示「● 已修改」
- 提供「恢复预设默认」

### 6.2 载入校验与降级

载入前检查字体 / 背景是否存在：

- 字体缺失：保留当前字体，提示「这个预设用的『华阳手写体』本机没有」+ 三个选项（换字体 / 定位文件 / 取消）
- 背景缺失：回退到 `backgrounds/A4纯白.webp`
- **不要**直接失败，更不要只写状态栏

### 6.3 错误即引导

`store.ts:640` 的渲染错误、`:1202` 的载入错误、`:1238` 的导出错误，统一改成：

- 预览区顶部横幅 / `useMessage` toast
- 文案包含「下一步按钮」：选择字体 / 选择背景 / 打开帮助

### 6.4 命名与分类

- 场景优先命名：「A4 白纸 · 工整」「信纸 · 日常」「作文纸 · 学生」，而不是「华阳体 白纸」
- 分类：日常 / 信纸 / 作文纸 / 试卷；加「推荐」标签
- 可选：120×160 缩略图（背景 + 3 行示例字）

### 6.5 切换预设不要清空文档

`store.ts:1178` 清空 `docPages` 的行为，对文档填空用户是破坏性的。建议：

- 文本模式：可以重置背景
- 文档模式：只更新排版 / 字迹参数，保留底图与区域；如必须清空，弹确认框

## 8. 实施计划

### P0 冷启动（0.5–1 天）

- 字体兜底：无字体时自动选系统楷体 / 首个中文字体，并提示
- 预设载入校验 + 缺字体 / 背景降级（保留当前值 + 横幅）
- 预设下拉保留当前值 + dirty 标记
- 空状态行动卡（4 个按钮）
- 渲染 / 导出错误改为横幅 + 动作

**验收**：全新机器、没有 `fonts/` 目录，打开 → 点示例 → 看到成品 ≤ 60 秒；点任意预设不再报错。

### P1 信息架构（2–3 天）

- 右栏重排：当前方案条 + ①②③ + 高级抽屉
- 正文编辑器改「摘要 + 弹窗」
- 条件显示（文本 / 文档模式）
- 底部按钮层级

**验收**：1280×900 下默认状态无需滚动即可完成主路径；两种模式面板不同。

### P2 引导（2–3 天）

- 首启任务选择 + 字体向导
- 三步清单
- 3 条情境提示
- 帮助重构 + 深链

**验收**：5 名未接触过软件的用户，至少 4 名能在 3 分钟内独立完成一次导出，且无人问「字体在哪」。

### P3 增强（可选）

- 示例工程、预设缩略图、简洁 / 专业双模式、30 秒演示视频

## 11. 如果只有半天

按顺序做这三件，用户至少能「用起来」：

1. **空状态 3 个按钮 + 示例**
2. **没有字体时自动用系统楷体 + 顶部提示**
3. **预设缺字体不报错，保留当前字体**

引导可以之后慢慢加，但这三件不做，任何教程都救不了第一次体验。

## 12. 可选：随包附带一款 OFL 字体

发布包不含商业字体是对的，但「一个字体都没有」会让首次体验无法闭环。可考虑：

- 随包附带霞鹜文楷（OFL 1.1，可再分发，需附许可证），约十几到二十 MB
- 或做常用字子集（注意 OFL 的 Reserved Font Name 条款）
- 或首次启动时提供「一键下载推荐字体」（走更新器同款下载通道）

这一条不是必须，但它能把「先找字体」从新手任务里彻底删掉。
