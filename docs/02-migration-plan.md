# 迁移计划（从 Python 版）

目标：把 `Handwriting-simulator`（Python + PyQt6 + numpy/scipy）迁移为
`handwrite-sim`（Rust + Iced + 自研引擎），按阶段推进、逐模块验证。

## 迁移原则

1. **复刻"行为"而非"像素"**：Rust 版对齐 Python 版的排版规则、换行规则、
   扰动分布、分页规则；像素级输出允许差异（字体光栅化 hinting/抗锯齿差异）。
2. **golden 验收**：用 Python 版生成基准样本（多字体 × 多背景 × 多样参数，
   固定 seed），Rust 版做视觉对比验收（允许亚像素级差异）。
3. **引擎冻结**：迁移期间冻结 Python 版引擎算法变更（只修 bug），
   控制回归面。
4. **seed 自洽**：Rust 版不要求与 Python 版 seed 兼容，但必须保证
   自身「同 seed 预览 = 导出」逐像素一致（已有测试保障）。

## golden 测试方案

1. Python 版固定 seed 生成样本集：

   ```
   golden/paramset-01/{seed,files...}
   ```

2. 覆盖维度：简体/繁体/标点、窄画布换行、end_chars 强制换行、
   大字号扰动、极端 sigma、多页长文。
3. Rust 版以同参数渲染，人工/脚本对比视觉差异（允许亚像素）。
4. 自动化：把对比脚本纳入 CI（可选）。

## 性能验证

- 基准：Python 版 `FastEngine` 全分辨率约 0.15s/页（采集自原项目注释）
- 目标：Rust 版单页 < 25ms（预计 6-15 倍提升）
- 验收：`cargo bench`（或简单计时测试）对比同参数渲染耗时
