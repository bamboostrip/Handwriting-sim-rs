# egui UI 迁移 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把手写模拟器的桌面 UI 从 iced 0.14 迁移到 egui 0.36 / eframe 0.36（glow 后端），实现段落编辑器内「wrap 换行后每行真对齐」（消除 iced 版的估宽 hack 与超长段回退），全部参数面板/预览/翻页/预设/docx/导出功能等价。

**Architecture:** egui 即时模式——`eframe::App::update(ctx)` 每帧直接读写 `&mut self` 状态渲染 UI，无 Message 枚举/subscription。段落编辑器每段一个 `TextEdit::multiline` + `desired_width(INFINITY)` + `horizontal_align`（epaint `halign_and_justify_row` 实现 wrap 后每行对齐）。后台渲染/文件对话框走 `std::thread::spawn` + `std::sync::mpsc`，完成时 `ctx.request_repaint()` 唤醒 UI。`core/` 引擎零改动；`ui/params.rs` 零改动；`ui/editor.rs` 从 iced `Content` 模型改为纯 `String` 模型。

**Tech Stack:** Rust 2021、eframe 0.36（glow/default_fonts/wayland/x11）、egui 0.36、保留 rfd/image/serde/zip/quick-xml/printpdf/lopdf/fast_image_resize/ab_glyph；移除 iced、tokio。

## Global Constraints

- 渲染后端固定 **glow（OpenGL）**：`eframe = { version = "0.36", default-features = false, features = ["glow", "default_fonts", "wayland", "x11"] }`。wgpu 不在主路径。
- `default_fonts` 必须保留（egui 默认不含 CJK，需手动加载中文字体）。
- `core/` 全部文件零改动；`ui/params.rs` 零改动（含 8 例测试）。
- egui/eframe 锁定 **0.36**；最低 Rust 1.95.0（CI 用 stable，满足）。
- 许可：MIT/Apache-2.0，消除 GPL 传染（iced 版已消除，egui 维持）。
- 字号基准 13px（对齐现状 Slint/iced 版编辑器字号）。
- 窗口 1280×840，标题「手写模拟器」，图标 app-icon.png。
- 测试目标：`cargo test` 全绿 ≥ 现状 77 例 + editor 新增；`cargo clippy --all-targets` 零警告。
- 不做字符级富文本、不做 Web/移动端、不做新功能（仅 UI 框架替换）。

## 控件映射速查（执行时对照）

| iced 现状 | egui 0.36 对应 |
|---|---|
| `text_editor::TextEditor`（每段） | `TextEdit::multiline(&mut para.text).show(ui)` → `TextEditOutput` |
| `text_input`（单行路径/颜色/θ） | `TextEdit::singleline(&mut s)` |
| `num_field`（SpinBox ± 按钮） | `DragValue::new(&mut v).range(min..=max).clamp_to_range(true)` |
| `pick_list`（预设/重写/涂改） | `ComboBox::from_id_salt(...)` |
| `slider`（错字率） | `Slider::new(&mut v, 0.0..=30.0)` |
| `checkbox`（边界提示） | `Checkbox::new(&mut b, "...")` |
| `button + green_button style` | `Button::new(...).fill(theme::BTN_BG).stroke(...)` |
| `button + primary_button style` | `Button::new(...).fill(theme::PRIMARY_BG)` |
| `container(group_box)` | `Frame::group(ui.style()).stroke(...).rounding(6.0)` |
| `image(Handle)`（预览） | `egui::Image::from_texture(texture_id)`（TextureHandle 缓存） |
| `scrollable` | `ScrollArea::vertical()` |
| `iced::time::every`（防抖） | `ctx.request_repaint_after(Duration)` |
| `tokio::spawn_blocking` | `std::thread::spawn + mpsc::channel` |

整体覆盖 `src/ui/editor.rs`，先写模块文档 + 数据结构 + 测试（编译会因函数体缺失失败，验证测试表达正确）。`#[cfg(test)] mod tests` 包含以下用例（基于 iced 版测试，去掉 `Content::move_to` 依赖，新增 Unicode 拆段）：

```rust
//! 段落编辑器（egui 版）：每段一个 TextEdit + 段级格式。
//!
//! 与 iced 版差异：段直接持有 `String`（egui TextEdit 即时编辑 String），
//! 光标位置由 UI 层（TextEditOutput::cursor_range）传入逻辑层，
//! 因此逻辑层是纯函数，无 iced Content::move_to 的非 ASCII bug——
//! 可对任意 Unicode 文本做光标处拆段测试。
//!
//! 关键约定：段内文本不含 `\n`（回车=分段、粘贴多行自动拆段）。

use crate::core::models::{Align, Paragraph};

#[derive(Debug, Clone, Copy, PartialEq, Default)]
pub struct ParaFormat {
    pub align: u8,
    pub indent_em: f32,
}

pub const DEFAULT_INDENT_EM: f32 = 2.0;

#[derive(Debug, Clone, Default)]
pub struct ParaEditor {
    pub text: String,
    pub format: ParaFormat,
}

impl ParaEditor {
    pub fn new(text: &str, format: ParaFormat) -> Self {
        Self { text: text.to_string(), format }
    }
}

#[derive(Debug, Default)]
pub struct ParagraphEditor {
    pub paras: Vec<ParaEditor>,
    pub current: usize,
}

impl ParagraphEditor {
    pub fn empty() -> Self {
        Self { paras: vec![ParaEditor::default()], current: 0 }
    }

    pub fn set_text(&mut self, text: &str, formats: Vec<ParaFormat>) {
        let texts: Vec<&str> = text.split('\n').collect();
        self.paras = texts
            .iter()
            .enumerate()
            .map(|(i, t)| ParaEditor::new(t, formats.get(i).copied().unwrap_or_default()))
            .collect();
        if self.paras.is_empty() {
            self.paras.push(ParaEditor::default());
        }
        self.current = 0;
    }

    pub fn text(&self) -> String {
        self.paras.iter().map(|p| p.text.as_str()).collect::<Vec<_>>().join("\n")
    }

    /// 回车分段：在 byte_pos 处拆分当前段，后半段继承格式，返回新段索引。
    /// byte_pos 由 UI 层从 TextEditOutput 光标位置提供。
    pub fn split(&mut self, para: usize, byte_pos: usize) -> Option<usize> {
        let editor = self.paras.get_mut(para)?;
        let mut pos = byte_pos.min(editor.text.len());
        while pos > 0 && !editor.text.is_char_boundary(pos) {
            pos -= 1;
        }
        let after = editor.text.split_off(pos);
        let format = editor.format;
        self.paras.insert(para + 1, ParaEditor::new(&after, format));
        self.current = para + 1;
        Some(para + 1)
    }

    /// 段首退格：并入上一段（格式保留上一段），返回合并后段索引。
    pub fn merge_prev(&mut self, para: usize) -> Option<usize> {
        if para == 0 || para >= self.paras.len() {
            return None;
        }
        self.paras[para - 1].text.push_str(&self.paras[para].text);
        self.paras.remove(para);
        if self.paras.is_empty() {
            self.paras.push(ParaEditor::default());
        }
        self.current = para - 1;
        Some(para - 1)
    }

    /// 段内含 `\n`（egui 回车/粘贴插入）→ 拆成多段，新段继承格式。
    /// 返回拆分后该 para 区域的最后一段索引（UI 聚焦用）。
    pub fn split_para_at_newlines(&mut self, para: usize) -> Option<usize> {
        let text = std::mem::take(&mut self.paras.get_mut(para)?.text);
        if !text.contains('\n') {
            self.paras[para].text = text;
            return None;
        }
        let format = self.paras[para].format;
        let parts: Vec<&str> = text.split('\n').collect();
        let new_paras: Vec<ParaEditor> =
            parts.iter().map(|p| ParaEditor::new(p, format)).collect();
        let last = para + new_paras.len() - 1;
        self.paras.splice(para..para + 1, new_paras);
        self.current = last;
        Some(last)
    }

    pub fn cursor_paragraph(&self) -> usize {
        self.current.min(self.paras.len().saturating_sub(1))
    }

    pub fn set_align(&mut self, align: u8) {
        let i = self.cursor_paragraph();
        if let Some(p) = self.paras.get_mut(i) {
            p.format.align = align.clamp(0, 2);
        }
    }

    pub fn toggle_indent(&mut self, on: bool) {
        let i = self.cursor_paragraph();
        if let Some(p) = self.paras.get_mut(i) {
            p.format.indent_em = if on { DEFAULT_INDENT_EM } else { 0.0 };
        }
    }

    pub fn current_format(&self) -> Option<ParaFormat> {
        self.paras.get(self.cursor_paragraph()).map(|p| p.format)
    }
}

/// 编辑器内容转引擎段落（跳过全空白段，保留首尾空格占宽）。
pub fn paragraphs_from_editor(
    editor: &ParagraphEditor,
    font_size: f32,
) -> (Vec<Paragraph>, bool) {
    let mut paras = Vec::new();
    let mut has_format = false;
    for para in &editor.paras {
        if para.text.trim().is_empty() {
            continue;
        }
        if para.format.align != 0 || para.format.indent_em != 0.0 {
            has_format = true;
        }
        paras.push(Paragraph {
            text: clean_editor_spaces(&para.text),
            align: match para.format.align {
                1 => Align::Center,
                2 => Align::Right,
                _ => Align::Left,
            },
            first_line_indent: para.format.indent_em * font_size,
        });
    }
    (paras, has_format)
}

pub fn clean_editor_spaces(s: &str) -> String {
    s.replace('\u{2060}', "").replace(['\u{00a0}', '\u{ffa0}'], " ")
}
```

```rust
/// 加载系统 CJK 字体到 egui（找不到则跳过，不 panic）。
fn setup_fonts(ctx: &egui::Context) {
    let mut fonts = egui::FontDefinitions::default();
    let candidates: &[&str] = &[
        "C:\\Windows\\Fonts\\msyh.ttc",      // Windows 雅黑
        "C:\\Windows\\Fonts\\msyhbd.ttc",
        "C:\\Windows\\Fonts\\simsun.ttc",
        "C:\\Windows\\Fonts\\simhei.ttf",
        "/System/Library/Fonts/PingFang.ttc", // macOS
        "/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc",
        "/usr/share/fonts/truetype/wqy/wqy-microhei.ttc",
    ];
    for path in candidates {
        if let Ok(bytes) = std::fs::read(path) {
            fonts
                .font_data
                .insert("system-chinese".to_string(), egui::FontSource::from(bytes));
            // 把 system-chinese 插入 Proportional 回退链最前
            if let Some(family) = fonts.families.get_mut(&egui::FontFamily::Proportional) {
                family.insert(0, "system-chinese".to_string());
            }
            break; // 用第一个找到的
        }
    }
    ctx.set_fonts(fonts);
}
```

```rust
            .inner_margin(6.0)
            .show(ui, |ui| {
                ui.set_width(ui.available_width());
                let mut actions: Vec<ParaAction> = Vec::new();
                let backspace_pressed =
                    ui.input(|i| i.key_pressed(egui::Key::Backspace));
                let n = self.editor.paras.len();
                for i in 0..n {
                    ui.push_id(format!("para-{i}"), |ui| {
                        self.render_one_para(ui, i, backspace_pressed, &mut actions);
                    });
                }
                // 底部空白点击 → 聚焦最后一段
                let bottom = ui.allocate_space(ui.available_size());
                if bottom.clicked() {
                    actions.push(ParaAction::FocusLast);
                }
                // 存到自身，帧末处理（update 末尾调用 apply_para_actions）
                self.drain_actions = actions;
            });
    });
}

/// 渲染单段：缩进留白 + 对齐的 TextEdit。
fn render_one_para(
    &mut self,
    ui: &mut egui::Ui,
    i: usize,
    backspace_pressed: bool,
    actions: &mut Vec<ParaAction>,
) {
    let (align, indent_em, has_focus_now) = {
        let p = &self.editor.paras[i];
        (p.format.align, p.format.indent_em, false)
    };
    let _ = has_focus_now;
    ui.horizontal(|ui| {
        if indent_em > 0.0 {
            ui.add_space(indent_em * EDITOR_FONT_SIZE);
        }
        let halign = match align {
            1 => egui::Align::Center,
            2 => egui::Align::RIGHT,
            _ => egui::Align::LEFT,
        };
        let text = &mut self.editor.paras[i].text;
        let had_newline = text.contains('\n');
        let prev_text_len = text.len();
        let output = egui::TextEdit::multiline(text)
            .id(egui::Id::new(format!("para-{i}")))
            .desired_width(f32::INFINITY)
            .desired_rows(1)
            .font(egui::TextStyle::Body)
            .hint_text("请输入文本内容…")
            .horizontal_align(halign)
            .show(ui);
        // 程序化聚焦（上一帧 set 的 pending_focus）
        if self.pending_focus == Some(i) {
            output.response.request_focus();
        }
        if output.response.changed() {
            // 回车/粘贴：含 \n → 拆段
            if self.editor.paras[i].text.contains('\n') {
                actions.push(ParaAction::SplitNewlines(i));
                self.mark_changed();
            } else if prev_text_len != self.editor.paras[i].text.len() || had_newline {
                self.editor.current = i;
                self.mark_changed();
            }
            self.refresh_para_status_after(i);
        } else if output.response.has_focus() {
            // 仅光标移动：更新当前段
            if self.editor.current != i {
                self.editor.current = i;
                self.refresh_para_status_after(i);
            }
        }
        // 段首退格：光标在段首 + 本帧 Backspace + 该段聚焦
        if backspace_pressed && output.response.has_focus() {
            if let Some(cr) = &output.cursor_range {
                let at_start = cr.primary.ccursor.index == 0 && cr.secondary.ccursor.index == 0;
                if at_start && i > 0 {
                    actions.push(ParaAction::MergePrev(i));
                }
            }
        }
    });
}
```

```rust
fn apply_para_actions(&mut self, ctx: &egui::Context) {
    let actions = std::mem::take(&mut self.drain_actions);
    for a in actions {
        match a {
            ParaAction::SplitNewlines(i) => {
                if let Some(last) = self.editor.split_para_at_newlines(i) {
                    self.pending_focus = Some(last);
                    self.mark_changed();
                    self.refresh_para_status();
                }
            }
            ParaAction::MergePrev(i) => {
                if let Some(t) = self.editor.merge_prev(i) {
                    self.pending_focus = Some(t);
                    self.mark_changed();
                    self.refresh_para_status();
                }
            }
            ParaAction::FocusLast => {
                let last = self.editor.paras.len().saturating_sub(1);
                self.editor.current = last;
                self.pending_focus = Some(last);
                self.refresh_para_status();
            }
        }
    }
    let _ = ctx;
}
```

```rust
        }
        _ => String::new(),
```

```rust
/// 在后台线程执行闭包，结果经 channel 回 UI，并 request_repaint 唤醒。
fn spawn_worker<F>(&mut self, ctx: &egui::Context, f: F)
where
    F: FnOnce() -> WorkerMsg + Send + 'static,
{
    let (tx, rx) = mpsc::channel::<WorkerMsg>();
    self.render_rx = Some(rx);
    let ctx2 = ctx.clone();
    std::thread::spawn(move || {
        let msg = f();
        let _ = tx.send(msg);
        ctx2.request_repaint();
    });
}
```

> 注：多个并发 worker 共用一个 `render_rx` 会丢消息。本应用后台任务串行（同一时刻最多一个），故单 channel 即可。对话框类（pick_*）若与渲染并发，可各用独立 channel——执行时按需扩展为 `Vec<Receiver>` 或 `HashMap`。**简化约定**：所有后台结果统一走 `render_rx`，且保证不并发（对话框期间不触发渲染——渲染触发由 dirty+防抖，对话框期间用户通常不在编辑，可接受）。若实测有丢消息，改为每类一个 channel。

```rust
/// 防抖：停止输入满 300ms 且无渲染中 → 后台线程渲染预览。
fn maybe_render(&mut self, ctx: &egui::Context) {
    if !self.dirty || self.rendering {
        return;
    }
    if self.last_edit.elapsed() < Duration::from_millis(PREVIEW_DEBOUNCE_MS) {
        // 还没到时间 → 安排一次到点唤醒
        ctx.request_repaint_after(Duration::from_millis(PREVIEW_DEBOUNCE_MS));
        return;
    }
    self.dirty = false;
    let font_size = self.ui.font_size as f32;
    let (paras, has_format) = crate::ui::editor::paragraphs_from_editor(&self.editor, font_size);
    let params = match crate::ui::params::collect_params(&self.ui, self.preset_params.as_ref(), paras, has_format) {
        Ok(p) => p,
        Err(e) => { self.status = format!("参数错误：{e}"); return; }
    };
    let bounds_visible = self.ui.bounds_visible;
    let bounds_color = crate::core::models::parse_color(&self.ui.bounds_color).unwrap_or([76,166,166]);
    self.seed += 1;
    let seed = self.seed;
    self.rendering = true;
    self.status = "渲染中…".to_string();
    self.spawn_worker(ctx, move || {
        let r = (|| -> Result<Vec<RgbaImage>, String> {
            let mut pages = crate::core::engine::render_all_pages_preview(&params, seed).map_err(|e| e.to_string())?;
            if bounds_visible {
                for page in pages.iter_mut() { *page = crate::core::engine::overlay_bounds(page, &params, bounds_color); }
            }
            Ok(pages)
        })();
        WorkerMsg::RenderDone(r)
    });
}
```

```rust
                .fit_to_exact_size(resp.rect.size())
                .paint_at(ui, resp.rect);
        }

fn ensure_preview_texture(&mut self, ui: &mut egui::Ui, img: &RgbaImage) -> Option<egui::TextureId> {
    let (w, h) = img.dimensions();
    let color_image = egui::ColorImage::from_rgba_unmultiplied([w as usize, h as usize], img.as_raw());
    let tex = self.preview_texture.get_or_insert_with(|| {
        ui.ctx().load_texture("preview_page", color_image.clone(), egui::TextureOptions::LINEAR)
    });
```

```rust
}

fn select_preset(&mut self, name: String) {
```
