fonts/ 目录说明
================

本目录用于存放手写字体文件（.ttf / .ttc / .otf）。

手写体多为商业版权字体（如汉呈、华阳、云江等字库），开源分发需授权，
因此软件不随包分发字体，请自行准备：

1. 放入你已有的字体文件（.ttf / .ttc / .otf），或
2. 从开源 / 免费可商用字体中下载，推荐：
   - 霞鹜文楷（LXGW WenKai）：OFL 1.1 协议，可商用，最接近手写体观感
   - 沐瑶随心手写体：免费可商用
   - 站酷小薇 / 站酷快乐体：免费可商用

预设中引用的字体路径（如 fonts/云烟体.ttf）为占位名称：
放入对应文件后即可直接使用，也可以改用其他字体（应用内重新选择即可）。
